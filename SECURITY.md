# Security and privacy

This public repository contains article drafts. A draft's `published: false` setting controls Zenn publication; it does not make its GitHub contents private.

If you find credentials or personal information that should not be public, use [GitHub private vulnerability reporting](https://github.com/RollNuts/zenn-content/security/advisories/new). Include the affected path and commit, and avoid copying the sensitive value into a public issue or pull request.

Before contributing, remove personal data, private correspondence, provider tokens, and secrets from text, screenshots, and logs. Use clearly fictional examples. If a real credential has been committed, revoke or rotate it; deleting the current text does not remove Git history.

Ordinary corrections can be proposed through a pull request. Reuse terms remain as described in [README.md](README.md).
